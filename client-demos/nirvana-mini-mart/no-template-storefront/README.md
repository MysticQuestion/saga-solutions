# Nirvana Mini Mart — No-Template Static Prototype

This folder contains a hand-coded, no-Lovable-credit microsite prototype for Nirvana Mini Mart.

## Purpose

Create a client-facing sample that does **not** rely on the recognizable default Lovable landing-page style. The goal is to show Nirvana a site that feels like its actual storefront: snack wall, apparel rack, drop board, delivery counter, social feed, and San Pablo Ave location identity.

## Files

- `index.html` — self-contained HTML/CSS prototype. No build step. No npm install. No Lovable. Open directly in a browser or deploy as static HTML.

## Design rules

Avoid the lazy Lovable template pattern:

- No generic gradient hero.
- No startup-style card grid as the main structure.
- No fake SaaS CTA section.
- No generic testimonials.
- No vague luxury copy without store-specific detail.

Use storefront-specific layout grammar instead:

- Awning / storefront window.
- Snack shelf grid.
- Apparel rack / hangtag cards.
- Drop board.
- Receipt-style reputation notes.
- Social media monitor wall.
- Delivery app counter stickers.
- Map / location card.

## Asset policy

Do not scrape or reuse public online photos as permanent site assets without permission. Safer options:

1. Owner-provided photos.
2. Official Instagram/TikTok embeds with attribution.
3. Placeholder visuals until the owner approves assets.
4. Confirmed delivery-platform links.

## Client edits needed

- Current exact hours.
- Confirmed DoorDash / Seamless / Facebook links.
- Exterior storefront photo.
- Interior snack wall photos.
- Apparel wall photos.
- Logo or preferred brand mark.
- Exact position on 21+ products: mention discreetly, or omit from public site.

## Deployment options

This can be deployed as static HTML through GitHub Pages, Vercel, Netlify, or Cloudflare Pages. No Lovable credits required.
